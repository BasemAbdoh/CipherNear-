# NearChat App - تطبيق المحادثة المحلي P2P (بدون إنترنت) 📱🔒

**NearChat** هو تطبيق محادثة ذكي ومتقدم يعمل بشكل **محلي تماماً (Offline 100%)** بدون الحاجة لاتصال بالإنترنت، متصل عبر شبكة Wi-Fi المحلية أو التقنيات اللاسلكية المباشرة (P2P / Wi-Fi Direct).

يتميز التطبيق بتشفير تام من طرف إلى طرف (End-to-End Encryption) مع مجموعة متكاملة من الميزات الحديثة مثل المحادثات الجماعية، الوسائط، الرسائل ذاتية التدمير، وتصدير النسخ الاحتياطية.

---

## 🌟 الميزات الرئيسية

### 1. 🔒 أمان وتشفير تام (End-to-End Encryption)
- **تبادل مفاتيح آمن**: اعتماد بروتوكول **X25519 (ECDH)** لتبادل المفاتيح العامة والخاصة بين الأجهزة.
- **تشفير متماثل**: تشفير كافة الرسائل والوسائط باستخدام **AES-256-GCM** مع نصوص مصادقة ومصادفة فريدة (Nonce) لكل رسالة.
- **عمل محلي 100%**: لا يتم إرسال أي بيانات إلى خوادم سحابية خارجية.

### 2. 💬 المحادثات الفردية والجماعية (Direct & Group Chats)
- **محادثات ثنائية**: تواصل مباشر بين شخصين مع مؤشرات حالة الإرسال والاستلام والقراءة (✓ / ✓✓ / ✓✓ باللون الأزرق).
- **مجموعات الدردشة (Group Chat)**: إنشاء مجموعات محلية وتوجيه الرسائل عبر المضيف (Host) مع تمييز اسم كل عضو بلون واضح فوق الفقاعة.

### 3. 📁 إرسال وتداول الوسائط والملفات
- دعم إرسال واستقبال **الصور**، **الفيديوهات**، **المقاطع الصوتية**، و**الملفات المستندية**.
- حفظ الوسائط تلقائياً في مجلد الجهاز `NearChat/Exports` ومجالس التنزيلات.
- معاينة واسعة للصور والفيديوهات ومشغل صوت مدمج.

### 4. ⏳ الرسائل ذاتية التدمير (Self-Destruct Messages)
- تحديد مؤقت زمني (TTL) للرسائل (مثل 10 ثوانٍ، دقيقة، إلخ).
- عداد تنازلي حقيقي يُظهر الوقت المتبقي قبل حذف الرسالة تلقائياً من الجهازين وقاعدة البيانات.

### 5. ⚡ التفاعلات والإشعارات التفاعلية
- **ردود الفعل (Emoji Reactions)**: إضافة تفاعلات سريعة على الرسائل (❤️ 👍 😂 😮 😢 🙏).
- **أصوات الإرسال والاستلام**: تنبيهات صوتية عند إرسال أو استقبال الرسائل.
- **إشعارات تفاعلية**: 
  - **الرد السريع**: الإجابة على الرسالة فوراً من داخل الإشعار دون فتح التطبيق.
  - **تمييز كمقروءة**: تحديث حالة الرسائل كمقروءة وإخطار الطرف الآخر فوراً.

### 6. 🔍 البحث والتصدير (Search & Chat Backup)
- **البحث في المحادثات**: البحث عن أي كلمة داخل سجل الرسائل وتظليل النتائج والتنقل بينها.
- **تصدير المحادثات (Backup)**: تصدير سجل الدردشة بصيغة ملف نصي `.txt` منسق أو ملف `.json` للنسخ الاحتياطي.

### 7. 📶 الاتصال والربط المباشر
- **الربط عبر رمز QR**: مسح QR Code للاتصال الفوري بين المضيف والعميل.
- **الاتصال المباشر عبر IP**: إدخال IP المضيف والاتصال بسلاسة عبر TCP Sockets (منفذ 8888).
- **بروتوكول Ping/Pong**: فحص حالة الاتصال الحية (متصل 🟢 / غير متصل 🔴) كل 15 ثانية.

## 🛠️ البنية التقنية (Tech Stack)

- **الإطار البرمجي**: [Flutter](https://flutter.dev) (Dart)
- **شبكة الـ P2P**: `flutter_p2p_connection` + `dart:io` TCP Sockets
- **التشفير**: `cryptography` (X25519 & AES-GCM-256)
- **قاعدة البيانات المحلية**: `sqflite` (SQLite Schema v10)
- **الإشعارات المحلية**: `flutter_local_notifications`
- **تشغيل الأصوات والوسائط**: `audioplayers`, `image_picker`, `file_picker`
